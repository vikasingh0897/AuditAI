### ❓ FAQ (5 Real Q&As)

**1. Is there a cost to run the audit?**
No, the audit tool is completely free. We provide transparency to help founders understand their actual AI overhead.

**2. Do I need to create an account?**
No login is required to use the tool. We prioritize instant value and only capture emails after showing the audit results.

**3. How accurate is the pricing data?**
All logic is based on official vendor pricing pages, updated to the current week. Every calculation is defensible and traceable.

**4. What happens if my spend is already optimal?**
We practice radical honesty. If you are already on the best plan, we will tell you. We don't manufacture fake savings to push credits.

**5. How is my data handled when sharing?**
Public shareable URLs are stripped of all identifying details like company names or emails. Only the tool stack and potential savings are displayed.
